Restaurant addresses (Wolt and Glovo)

Paste each restaurant's own page address from wolt.com or glovoapp.com once. The "Fetch prices" button on the Add tab uses them, one page at a time with a pause between pages.

Automatic fetching

When this is on, the site fetches the prices from the saved addresses by itself, on the days and hours you choose (once or twice a day), and saves them straight into the history (no checking step). Each run is saved with its time, like "10th November 2026 13:00", so a second run on the same day never replaces the first. It never touches rows you have waiting to be saved. A run can take a few hours because pages are fetched slowly, a few at a time.
